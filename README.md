# ぽこ！

1歳半の子どもがタップして遊ぶ**さかなたたき**アプリ。
水たまりから魚が「ばあっ！」と出てきて、叩くと「いてっ」と言って引っ込む。
画面の上の岩を押すと、隠れていた魚が手前へ突き出してくる。

設計と判断の記録は `mogura-app-design.md`（節番号 §4-8 などはそこを指す）。
**迷ったら設計書を読むこと。**

## 開発

```bash
npm install
npm run dev        # 開発サーバ（Service Worker は無効）
npm run verify     # typecheck + 単体 + E2E。**出す前に必ず通すこと**
```

| コマンド | 何をするか |
|---|---|
| `npm run build` | 型チェック + 本番ビルド（`dist/`） |
| `npm run test` | Vitest（不変条件を数値で押さえる 63件） |
| `npm run test:e2e` | Playwright（**本番ビルドに対して**走る 23件） |

E2E は `playwright.config.ts` の `webServer` が `npm run build` を走らせるので、
**本番と同じ設定**（base `/`・Service Worker あり）で検証している。

## 公開（本番）

**Netlify。`main` に push すると自動で公開される**（`netlify.toml`）。

- ビルドは `npm run build`、配信は `dist/`
- **`BASE_PATH` を設定しないこと。** Netlify はサイト直下で配信する
- `main` へのマージは**必ず人間が判断する**（設計書の不変条件10）

初回だけ Netlify 側で「GitHub の `mogura` リポジトリを繋ぐ」設定が要る。
繋がっていなければ `main` に push しても何も起きない。

**無料プランは右下に「Powered by Netlify」のバッジを入れる。**
バッジはリンクなので押すと外部サイトに飛ぶ（子ども向け画面に外部リンクを
置かないという決まりに触れる）。`src/ui/styles.css` の `--badge-reserve` で
当たり判定を逃がしてあるが、気にするなら Cloudflare Pages
（無料・バッジなし・private 可）に移す。

## 素材

`public/` に置く。**1つも無くてもアプリは起動する**（不変条件7）。
無ければ手続き生成の魚とグラデーションに落ちるだけ。

| 置き場所 | 中身 | 無いとどうなるか |
|---|---|---|
| `models/` | 3D の魚（`.glb`。みずのなかから） | canvas の絵に落ちる |
| `textures/` | 体の絵（`.jpg`） | モデルの色で塗る |
| `videos/` | 背景のループ動画（`.mp4` / `.webm`） | 手続き生成の水中に落ちる |
| `backgrounds/` | 背景の静止画（`.webp`） | 同上 |

**置き場所を増やしたら `vite.config.ts` の `runtimeCaching` にも足すこと。**
足し忘れるとオフラインでキャッシュされないが、フォールバックが効くので
**「一応動く」から気づけない**（実際に v0.4 でやった）。
